# Local browser tools

These tabs run in your browser. No dataset upload to Geckodupe for processing.

## Text Data

Paste or drop text, CSV, Excel, JSON, logs, code, and lists. Normalize and remove duplicate lines / rows.

## Directories

Load a folder or zip. Find duplicate files and duplicate lines inside files. Download a cleaned zip.

## Media

Find visually similar images and videos (bursts, resizes, re-exports). Optional reference-target mode.

## Spam (Despam)

Paste form dumps, lists, or logs. Score and strip spam locally. Hosted prevention for apps lives on the API.

## Guest caps

Soft daily limits apply until you sign in. Banners on each tab show your current plan caps. Sign in on **Account** or upgrade on **Pricing** for more headroom.

## Privacy

Local tools keep content on device. API usage is separate and only happens when your servers call the Worker with a key.
