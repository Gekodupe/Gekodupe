# Local browser tools

These tabs run entirely in your browser. Datasets are not uploaded to Geckodupe for processing.

## Text Data

Paste or drop text, CSV, Excel, JSON, logs, code, and lists. Normalize and remove duplicate lines or rows.

## Directories

Load a folder or zip. Find duplicate files and duplicate lines inside files. Download a cleaned archive.

## Media

Find visually similar images and videos (bursts, resizes, re-exports). Optional reference-target mode.

## Spam

Paste form dumps, lists, or logs. Score and strip spam locally. Hosted prevention for apps is available through the API.

## Quotas

Soft daily limits apply until you sign in. Banners on each tab show your current caps. Sign in on **Account** or upgrade on **Pricing** for more headroom.

## Privacy

Local tools keep content on the device. Hosted API traffic only happens when your servers call Geckodupe with an API key.
